Copyparty 文件共享 — 使用说明
================================

一、第一次打开（只需做一次）

1. 解压后，把 Copyparty 拖到「应用程序」或桌面（一定要先拖出来再打开）。
2. 双击 Copyparty。系统会提示「无法打开」或「无法验证开发者」，点「完成」。
3. 打开「系统设置 → 隐私与安全性」，往下滚动，找到关于 Copyparty 的提示，
   点「仍要打开」，输入开机密码确认。
4. 再次双击 Copyparty 即可。

如果提示没有安装 Python 3：点弹窗里的「安装」，按苹果的安装窗口装完
「命令行开发者工具」（免费，需要联网，约几分钟），再双击 Copyparty。

二、日常使用

1. 双击 Copyparty。
2. 第一次会让你设置用户名和密码（密码至少 8 位）。
3. 选择要加入影音库的文件夹（可以一次选多个），再选权限：只读 / 可上传和删除。
   选过的文件夹会记住，下次启动直接点「下一步」即可。
4. 弹窗会显示访问地址，例如 http://192.168.x.x:3923/
   同一个 Wi-Fi 下的手机、电脑用浏览器打开这个地址，输入密码即可。
5. 如果系统问是否允许 Python 接受传入连接，点「允许」。
6. 第一次启动需要联网，会自动安装图片缩略图组件（约 10 秒）。
7. 第一次启动会问是否下载 FFmpeg 组件（约 60 MB），用来显示视频和音乐的封面。
   点「下载」后请等待一两分钟，期间没有进度条，不要重复打开。
   不需要视频封面可以点「这次跳过」或「以后不再问」。

服务运行时再次双击 Copyparty，可以：打开页面 / 查看访问地址 /
管理共享目录 / 停止服务。

添加或移除要扫描的文件夹：双击 Copyparty → 管理共享目录 →
添加文件夹… 或 移除文件夹…（移除只是不再共享，不会删除文件）。
服务会自动重启，新文件夹扫描完就出现在影音库里。

三、影音库界面

- 打开地址后是「影音库」界面：首页、视频、图片、音乐、收藏、文件夹。
- 点视频或图片会在浮动窗口里打开，可以拖动、拉边角缩放、缩小到角落，
  也可以同时开多个；底部工具条可以平铺、多窗口一起全屏。
- 视频会记住看到的位置，下次打开自动续播；收藏和进度保存在这台电脑上，
  用同一个密码登录的手机、电脑看到的是同一份。
- 文件改名或移动到别的子文件夹后，播放进度和收藏会自动跟过去
  （按文件大小加内容指纹识别是不是同一个文件）。
- 设置（齿轮）里可以导出、导入播放记录和收藏，用于备份或搬到另一台电脑。
- 第一次启动、或文件很多时，建立索引需要一些时间，期间内容可能显示不全。
  新放进文件夹的文件最多 5 分钟后出现，也可以点右上角的刷新按钮。
- 浏览器放不了的格式（如部分 MKV、HEVC、AVI）会提示下载或复制链接，
  用 IINA、VLC 等播放器打开。
- 文件管理在「文件夹」页面：新建文件夹、上传（也可以把文件直接拖进页面）、
  打包下载；点「多选管理」可以批量重命名、移动、复制、下载、删除；
  在任意文件或文件夹上点右键也有这些操作。需要启动时选了「可上传和删除」。

四、注意

- 连接没有加密，只在家里或公司等可信的 Wi-Fi 下使用，公共 Wi-Fi 不要开。
- 密码以明文保存在本机（只有你的账户能读），不要用和银行、邮箱相同的密码。
- 关机或重启后服务不会自动启动，需要再双击一次。
