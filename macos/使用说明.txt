影音库（copyparty-media-wall）— 使用说明
==========================================

一、第一次打开（只需做一次）

1. 解压后，把 Copyparty 拖到「应用程序」或桌面（一定要先拖出来再打开）。
2. 双击 Copyparty。系统会提示「无法打开」或「无法验证开发者」，点「完成」。
3. 打开「系统设置 → 隐私与安全性」，往下滚动，找到关于 Copyparty 的提示，
   点「仍要打开」，输入开机密码确认。
4. 再次双击 Copyparty，浏览器会自动打开设置页面。

如果提示没有安装 Python 3：点弹窗里的「安装」，按苹果的安装窗口装完
「命令行开发者工具」（免费，需要联网，约几分钟），再双击 Copyparty。

二、在浏览器里完成设置（约一分钟）

按页面上的步骤走：
1. 设置用户名和密码（密码至少 8 位）。
2. 添加要放进影音库的文件夹，可以添加多个。
3. 选择其他设备的权限：只读 / 可上传和删除。
4. （可选）下载 FFmpeg 组件，用来显示视频和音乐的封面，约 60 MB。
完成后服务自动启动，页面上会显示访问地址。

如果系统询问是否允许访问某个文件夹，或是否允许 Python 接受传入连接，
请点「允许」。

三、日常使用

- 双击 Copyparty 打开管理页面：可以打开影音库、查看访问地址、
  添加或移除文件夹、修改权限和密码、停止或重启服务。
- 管理页面只能在这台电脑上打开，其他设备打不开。
- 同一个 Wi-Fi 下的手机、平板、电脑，用浏览器打开页面上
  「其他设备」那一行的地址，输入密码即可。
- 电脑重启后服务不会自己启动，双击一次 Copyparty 即可恢复。

四、影音库界面

- 首页、视频、图片、音乐、收藏、文件夹；右上角可以切换中文 / English。
- 点视频或图片会在浮动窗口里打开，可以拖动、缩放、缩到角落，
  同时开多个；底部工具条可以平铺、多窗口一起全屏。
- 视频会记住看到的位置；收藏和进度所有设备共用一份。
- 文件改名或移动后，播放进度和收藏会自动跟过去。
- 文件管理在「文件夹」页面：新建、上传（可拖入）、重命名、移动、
  复制、删除、打包下载；右键菜单里可以生成分享链接。
- 浏览器放不了的格式（如部分 MKV、HEVC、AVI）会提示下载，
  用 IINA、VLC 等播放器打开。

五、注意

- 连接没有加密，只在家里或公司等可信的 Wi-Fi 下使用，公共 Wi-Fi 不要开。
- 密码以明文保存在本机（只有你的账户能读），不要用和银行、邮箱相同的密码。
- 第一次启动或文件很多时，建立索引需要一些时间，期间内容可能显示不全。
